# Saathi prototype

House help at your door in 15 minutes. This Storybook is the working prototype for the three Saathi products,
built from the design in `web/design/`.

| Product | Built with | Where |
|---|---|---|
| **Saathi** customer app | React Native (rendered on the web with react-native-web) | `src/apps/customer` |
| **Saathi Partner** helper app | React Native | `src/apps/partner` |
| **Saathi Admin** operations panel | React (DOM) | `src/apps/admin` |

## How to use it

- **Prototype** stories under each product are the complete clickable app. Start at sign-in. In both apps the SMS code is **4821**.
- **Design pages** group every screen the way the design draws it, by release: **V1 · Launch**, **V2**, **V3**. Each opens with a story that lays the screens side by side; every phone is live. Filter the sidebar by the `v1` / `v2` / `v3` tags.
- **Components** is the design system: every React Native and admin component with its props and variants. **Foundations** shows the colours, type, spacing, icons and characters they are built from.
- The toolbar switches the four launch conditions the design requires, for every phone at once: **dark mode**, **large text**, **Hindi**, and **small phone**.

## Code map

Dependencies point down only (see **Saathi/Architecture** or `docs/ARCHITECTURE.md`):

| Layer | Where | What |
|---|---|---|
| Apps | `src/apps/{customer,partner,admin}` | `features/<name>/` (screens, components, hooks, data), `state/`, `navigation/` (routes, route table, tabs), `design-pages/` |
| Design systems | `src/native/ui`, `src/apps/admin/ui` | one folder per component, each with a story |
| Domain | `src/domain` | services, prices, codes, formatting, Hindi word lists; launch values in `src/data/launchValues.ts` |
| Tokens | `src/tokens` | colours, type, spacing, radii, elevation |

Route names and which release, design page and feature each belongs to: `ROUTES.md` in each app (`PAGES.md` for admin).

Run `npm run storybook` locally, `npm run check` before a pull request.
